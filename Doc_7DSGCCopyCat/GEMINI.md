# Antigravity Project Rules

Follow `AGENTS.md` as the shared project instruction entrypoint.

When starting an agent task:

1. Read `AGENTS.md`.
2. Use the orchestrator prompt at `Docs(Template)/AgentPrompts/orchestrator-agent.md`.
3. Load only the current task card, relevant workflow, relevant role prompt, and relevant GDD/ADR/rules sections.

Do not paste or load the entire `Docs(Template)/` folder unless the user explicitly asks for a full documentation audit.
