# Item and Material Art Brief

Inventory audit of the current project’s `ItemCatalog` and character data. The catalog defines the shared currency, progression-material, series-material, and artifact item families. Character Dupe Token is generated as a separate runtime item identity for each fighter. All currently authored fighters belong to KOF, so KOF is the only series with a live roster-backed series material. The catalog can generate series materials for other series IDs, but those are not currently represented by authored fighters.

## Shared image-generation direction

Use these prompts for isolated inventory icons, one item per image, centered and fully in frame, square canvas, transparent background. Match the completed artifact icon style: simplified broad shapes, smooth pastel cel-shaded rendering, clean controlled dark colored outlines, gentle highlights, low detail, and restrained contrast. Keep silhouettes readable at small UI size. Avoid harsh black shadows, scratchy or broken linework, stray strokes, noisy texture, tiny filigree, text, lettering, numbers, labels, watermarks, background scenes, extra objects, and cropped edges. Retain each item’s distinct hue and silhouette.

## Catalog

Diamond and Coin are completed standalone 1:1 transparent PNG assets in Assets/Project/Art/UI/Currency. Artifact Dust, all five Launch–META Sigils, and all nine phase Crests are completed standalone 1:1 transparent PNG assets in Assets/Project/Art/UI/UpgradeMaterials. Character Dupe Token is a per-character item identity at runtime; its item ID includes the fighter definition ID, and each fighter’s amount is stored separately.

## Coverage notes

- The 9 phase crests and 5 sub-phase sigils are generated by the core catalog and are all included above.
- The authored character assets currently use `series.kof`. The code has display-name mappings for Tekken, Soul Calibur, and Genshin Impact, and can construct generic series material definitions from other `series.*` IDs; those additional materials do not currently have roster-backed inventory entries in the authored character data, so they are excluded from the concrete item rows.
- Artifact rarity entries and Artifact Dust exist in the catalog, but their equipment and upgrade systems are described in code as future/prototype functionality.
- Character Dupe Token stacks are character-bound: a Kyo ’94 duplicate token is stored and spent only against Kyo ’94. The former shared post-C5 balance is retained only as a legacy save field and is not granted by new summons.
- Diamond, Coin, Artifact Dust, all five Launch–META Sigils, and all nine phase Crests are transparent 1254 × 1254 PNGs matching the artifact illustration style.
