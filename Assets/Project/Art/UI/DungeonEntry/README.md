# Choose a Dungeon

Reference: `Doc_7DSGCCopyCat/Docs(Template)/3_Outputs/Reports/visual-design/fighting-allstar-dungeon-selection-mockup.png`.

The Combat scene's DungeonEntryUI uses Assets/Project/UI/DungeonEntry.uxml and native flex layout. Fixed1920PanelSettings uses Constant Pixel Size at scale 1, with 1920 × 1080 as the reference viewport. Other viewports reflow; there is no whole-screen fit transform. The dungeon list retains vertical scrolling with hidden scrollbars. The selected dungeon stage preview fits its panel without scrolling, alongside a docked entry action. Phase/Sub-Phase are contained in its Stage Filter.

`ReferenceAtlas.png` is an unchanged copy of the supplied mockup. Native UXML elements clip its card illustrations and arena strip. The shared header supplies the same logo, avatar, and live Diamond balance used by all five screens. Buttons, text, controls, hover/focus states, and selection borders use UXML/USS. Stage Info contains route, filter, difficulty and reward information; the character catalog is only in Dungeon Preview. Fighters are first filtered by stage and dungeon policy, then sorted by descending rarity and name. Eligible fighters that are unowned or not runtime ready receive a translucent black overlay over their original artwork. Policy-excluded characters are omitted. The arena plate was edited with the built-in ImageGen tool; the exact prompt is below.

Each dungeon card owns its series. There is no global KOF/series dropdown. The selected Phase/Sub-Phase and dungeon policy determine preview membership. Legacy Women's profiles preserve their saved restrictions. Entry uses the existing run creation, route map and loadout flow. Regular routes have nine rows including Start. Difficulty is 1–5 (Easy through Nightmare). Reward samples are on the front page, with only the highest possible artifact tier and compact item tooltips. Every battle victory pays fixed currency, material quantities within a range, and a chance for an artifact instance. There is no dungeon-clear bonus. Fighter Preview shows the policy-filtered catalog; actual enemy formations are rolled and saved on entry. Team formation is selected in the UI Toolkit Character Loadout screen after entry.

## Verification

`Fighting Allstar > Validate Dungeon Selection Layout` renders the real document into an isolated editor preview scene at 1920 × 1080. It checks difficulty rewards, unavailable-category and insufficient-ownership entry blocking, Women's selection and saved-profile restrictions, both profiles' run generation, and Preview open/close. It uses an in-memory test inventory and generates temporary runs without saving a player run, spending currency, or saving a scene or account. Captures and results are written to `Artifacts/DungeonEntry/`. Runtime and editor assemblies also compiled successfully with the project's Unity 6000.3.4f1 compiler.
