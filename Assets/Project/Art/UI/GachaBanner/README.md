The selected configuration controls the title, artwork, pool preview, rates, selector candidates and pulls. No promotional rate-up, limited-time expiry, ten-pull guarantee or history feature is invented from the supplied reference. Layout dimensions are starting values: inspect long banner names and a list exceeding the viewport at 1920×1080, 1280×720 and 768×1024; if cards or actions clip, reduce padding or reflow copy before reducing legibility. Inspect repeated selection, invalid/empty lists, insufficient balance, Details/Escape, selector candidates and results/Continue in Play Mode. Browsing must never spend or save account data.
